# Syahlan Digital Web Builder

A multilingual digital-presence platform designed to help entrepreneurs, cooperatives and organisations activate a professional website through a clear, affordable and guided service journey.

## Product Purpose

Many small organisations understand that they need a credible website but struggle with technical setup, content structure, domains, hosting and ongoing management. This prototype demonstrates how those barriers can be converted into a simple customer journey.

## Core Experience

- outcome-led website service presentation;
- multilingual content across Bahasa Melayu, English, Mandarin and Iban;
- transparent packages and service inclusions;
- guided enquiry and onboarding journey;
- campaign progress and community-impact messaging;
- responsive landing-page experience;
- Netlify-backed content and submission infrastructure.

## Capabilities Demonstrated

Digital product positioning, conversion-focused information architecture, multilingual experience design, accessible responsive delivery and rapid deployment.

## Technology

HTML · CSS · JavaScript · Netlify Blobs · Responsive web design
